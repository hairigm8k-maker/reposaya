Developer Tooling

Deploy From Terminal with hh-cli-deploy

Built for developers, students, and power users. Works on Termux (Android phone), macOS, Linux, and Windows PowerShell. Deploy in just one command: hh deploy.

  • hh login <key> — authenticate with your dashboard API key
  • hh deploy ./dist — deploys local folder directly to your subdomain
  • hh list & hh whoami — inspect deployments and active account
  • Perfect for GitHub Actions, GitLab CI, and automated build scripts
